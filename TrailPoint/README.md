# TrailPoint Android app

Jetpack Compose Gradle project for the TrailPoint coding exercise.

- Package overview: [../README.md](../README.md)
- Mock server and API: [../mock-server/README.md](../mock-server/README.md)

## Open in Android Studio

Open this `TrailPoint/` directory (the folder with `settings.gradle.kts`).

## Build and test

From this directory:

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest
```
